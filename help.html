Simple Write

A word processor that keeps your work as Markdown: write as in Word, with equations, figures, tables, footnotes, comments, citations and cross-references, and get files that any Markdown tool, AI chat or Pandoc can read. It reads and writes Word (.docx) files too.

Getting started

Type in the page as in any word processor. The Document / Markdown switch at the top right (Ctrl+/) shows the same text as Markdown source, where you can also edit; switching back shows the result.

Each browser tab is one document. To work on two documents, use File ▸ New (a new tab) and cut and paste between tabs freely: equations, footnotes and the rest survive the trip.

Everything you type is kept in this browser as a draft, so reloading the page or closing the tab by accident loses nothing. Earlier documents are listed in File ▸ Recent drafts. Drafts live only in this browser: save to a file to keep your work for good or to move it to another computer.

Markdown shortcuts also work while typing: # to ###### at the start of a paragraph make headings, - a bulleted list, 1. a numbered list, > a quote, [ ] a checklist, and $x^2$ becomes an equation as soon as you type the closing dollar sign.

Saving a document with pictures

In Chrome and Edge, Save asks for a folder the first time and writes name.md, the images folder and references.bib there; later saves (Ctrl+S) update the same files. Other browsers download a .zip with everything inside, which Open reads back.

Everything in one .zip

Save as ▸ Everything in one .zip packs the document with its pictures, video, audio and references in a single file, so nothing gets separated when you move or send it. Open the .zip (or drop it on the window) to load it again.

Opening a document with pictures

Use File ▸ Open folder and pick the folder that holds the .md file and its images folder, or select the .md file together with its pictures in the Open window, or open the .zip.

Word files

  • Word files keep headings, lists, tables, pictures, captions, links, footnotes, comments and equations. The table of contents becomes a Word contents field (right-click it in Word and choose Update Field).
  • Opening a Word file brings back text, headings, lists, tables, pictures, footnotes and equations. Shapes and text boxes come in as their text, and charts as a table of their data; other drawings are replaced by a note. Citations and cross-references come back as plain text, keep the .md file as your master copy and send .docx copies.
  • Numbered equations are written the way Word numbers them (equation#(1)).

Formatting

The toolbar works as in Word. Bold, italic, strikethrough, inline code, headings, lists, quotes and links are plain Markdown. Underline, subscript, superscript, color, highlight, font, size and paragraph alignment are kept as small pieces of HTML inside the Markdown, which most Markdown programs display; they are dropped by programs that only understand plain text.

The format painter copies the formatting at the cursor: press it, then select the text that should get the same formatting. Clear formatting (Ctrl+Space) removes character formatting from the selection.

Font, size and line spacing for the whole document are set in File ▸ Page and document setup.

Equations

Press ∑ or Alt+=. Type LaTeX, or click the palette (structures, Greek letters, operators, arrows, accents, and a tab of engineering symbols); the preview shows the result as you type. Tick Display for an equation on its own line and Numbered to give it a number that cross-references can use. Double-click an equation to change it.

In the text you can also type $...$ directly. Equations pasted from Simple Solver, Word, Wikipedia, AI chats or other KaTeX and MathJax pages are converted to LaTeX: exact when the source carries LaTeX, as well as possible from MathML otherwise.

A dollar sign followed by a digit or a space, as in $5, stays a dollar sign. Supported LaTeX: KaTeX functions.

Pictures, tables, code

Equations, pictures, code blocks, footnote marks, citations and cross-references are objects: click one to select it (Delete removes it, the arrow keys move past it), double-click or press Enter to edit it.

  • Pictures: paste, drag them in, or use the picture button. A picture with a caption becomes a figure, numbered if you tick Numbered. Click a picture to get corner handles (drag to resize freely, the shape is kept), width buttons, and text-wrapping buttons: In line, Left and Right (text flows around it) and Center (alone on its line). The side handles stretch it (width or height alone), and Auto or a percentage gives back its own shape. The bar also rotates it left or right, flips it, and crops it (drag a box over the picture). Rotating, flipping and cropping save a new copy of the picture in the images folder, so Word and PDF show the same; Ctrl+Z brings the old one back. The Markdown records the layout as {width=320px height=180px float=left}.
  • Tables: the first row is the header. While the cursor is in a table, a small bar above it adds and deletes rows and columns, aligns columns and edits the caption. Tab moves to the next cell and adds a row at the end.
  • Tables from a spreadsheet file: Insert ▸ Table from a CSV file turns a .csv or .tsv file (save one from Excel, Numbers or Google Sheets) into a table at the cursor. The first row becomes the header; comma, semicolon and tab files are recognized, and columns of numbers are right-aligned. It inserts the first 1,000 rows. Formulas and formatting stay behind in the spreadsheet.
  • Code blocks (Insert ▸ Code block) are colored by language.
  • Page breaks (Ctrl+Enter) and the table of contents are in the Insert menu; the contents update by themselves.

Video and audio

Insert ▸ Video or audio… (or drop the file on the window) puts the file in the document with the browser's own player, so it plays wherever the browser can play that format: MP4 (H.264), WebM and MP3 are safe choices; some phone .mov files are not. The file is kept in a media folder like pictures are, and the Markdown holds a plain <video src="media/clip.mp4" controls></video> line. Save puts the files in the folder (or the .zip) with the document. In Present the player works on the slide (click its controls; the slide does not advance), and it stops when you move on. Word and plain-text files get a line such as [Video: clip.mp4] instead, because they cannot play it; a web page embeds files under 10 MB. The file stays in memory while you edit, so avoid files of many hundreds of MB.

Insert ▸ Video or audio from a web address… takes a link instead of a file. A link to a video or audio file (.mp4, .webm, .mp3, …) gets the ordinary player, with the usual size, rotate, crop and position controls. A YouTube or Vimeo link becomes an embedded player that can be resized and positioned but not rotated or cropped. Nothing is copied into the document or the .zip: it plays only while you are online and only if the website allows it, and Word, text and print show just the address. For a presentation where a video must not fail, insert the file itself.

YouTube “Error 153” (black player): YouTube plays an embedded video only when the page comes from a web address. Opened straight from a folder (file://), the page has no address to show YouTube, so it refuses. Use the app from its https address (or a local server such as python3 -m http.server and http://localhost:8000); the Open in a new tab link under every online player is the fallback.

Click a video or audio to get its bar: 25% … 100% and Auto set the size, and dragging a corner handle resizes it. For video, the rotate buttons turn it by 90° (for a clip shot upright on a phone) and Crop… lets you drag a box over a frame, or press Trim black bars to find the bars and cut them off. These only change how the video is shown: the file itself is not re-encoded, so nothing is lost and undo is exact. Left and Right put the player beside the text, which flows around it (as with pictures); Center keeps it alone on its line. They are stored as width, data-float, data-rotate and data-crop on the video line, and apply in the editor and in Present, not in other programs.

Numbering, cross-references, citations

Figures and tables with Numbered ticked, and numbered equations, are numbered in order and renumbered whenever you add, move or delete one. Insert ▸ Cross-reference lists everything you can refer to (also headings) and inserts “Figure 2”, “Table 1”, “Eq. (3)” or “Section 2.1”, kept up to date.

Insert ▸ Citation inserts numbered citations like [1] or [2–4] and builds the References list at the end. Add references by pasting BibTeX entries (in Google Scholar: Cite ▸ BibTeX) or loading a .bib file. The references are saved as references.bib beside the document.

Heading numbers (1, 1.1, 1.2…) are switched on in Page and document setup.

Footnotes and comments

Footnotes (Ctrl+Alt+F) are numbered by themselves and listed at the end of the page as notes; Word files get real footnotes at the bottom of the page.

Comments (Ctrl+Alt+M): select some text and type the comment. Comments show in the comments pane (View menu), with your name (File ▸ Your name for comments). They are not printed. In Word files they become real Word comments.

Page setup and printing

View ▸ Ruler shows a ruler above the page. Drag the triangles to set the left and right margins. Click the ruler to add a tab stop, drag a stop to move it, double-click it to remove it. Tab in a paragraph inserts a tab that jumps to the next stop (every half inch past the last one you set). Margins and tab stops are document settings, stored at the top of the Markdown file; tabs are stored as &#9;. View ▸ Two columns (or Page setup) lays the text out in two columns, with level-1 headings spanning both; in the Markdown this is classoption: twocolumn.

Zoom: the slider and menu in the status bar, Fit width, Ctrl+wheel, Ctrl+Alt++ / −, and Ctrl+Alt+0 for 100%.

File ▸ Page and document setup sets the paper (Letter, A4, or a screen size for slides), margins, font, font size, line spacing, a header text, page numbers and heading numbers. The page on screen follows these settings; Print (Ctrl+P) and Word files use them too. Page numbers in print need a recent Chrome or Edge.

The View menu has the outline pane (click a heading to go there), the comments pane, dark mode and focus mode (no toolbars; Esc leaves). Super-focus (Ctrl+Shift+F) is focus mode in full screen, so the browser's own toolbars go away too; Esc leaves it. The button at the top right switches between the formatted document and the Markdown source (Ctrl+/). Zoom is at the bottom right. The ¶ button (Ctrl+Shift+8) shows tabs and paragraph ends. Switching views keeps your cursor at the same place. Tabs delete with Backspace or Delete. Page setup has an inches/centimeters switch at the top; it changes the margin choices and the ruler, and is remembered in your browser (the file itself just records the margins in the unit you chose).

Headers and footers

In File ▸ Page and document setup, Header text and Footer text appear on every page, and Page numbers at the bottom adds the page number. Write left | center | right to put text in three places, for example {title} | | Thermo 301. These are filled in automatically: {page}, {pages} (the number of pages), {title} (the title in the front matter, or the first heading), {author} and {date} (the date in the front matter, or today). Nothing in the header and footer on the first page leaves page 1 clean. They are stored in the front matter as header, footer and skipfirst.

On screen the page is cut where the text runs past the bottom margin, like the printer does, with a gap between the sheets as at a page break. The page numbers, headers and footers follow those cuts (and your own page breaks), and the status bar shows the number of pages. A paragraph, list item, picture or table is never split between two sheets: one that does not fit moves whole to the next page, and a heading moves with the text after it. So the screen may show a few more pages than a printer or Word does; print, PDF (Ctrl+P) and Word files show the exact page numbers. Slides (the screen paper sizes) and two-column pages are not cut automatically: there a page is what you separate with page breaks, and each slide shows its own number in Present.

Install and offline use

When Simple Write is opened from a web address (https, or localhost), the browser can install it: in Chrome use the install icon in the address bar or Install Simple Write in the menu; on an iPhone or iPad use Share ▸ Add to Home Screen. After the first visit all the files are kept on the device, so the app opens and works with no Internet. Whenever there is a connection, the app checks for changed files each time it opens and uses the new ones, so updates arrive by themselves (reopen once to see them). Opening index.html straight from a folder works too, but cannot be installed.

Slides

A document can be a slide show. In Page and document setup choose the paper Screen 16:9 (or 4:3): the page becomes screen-shaped, with big type. Each page, up to the next page break (Ctrl+Enter), is one slide. A slide that holds only a heading and a line or two is centered as a title slide.

View ▸ Present from the start (F5) or from this page (Shift+F5) shows the slides full screen. Forward: →, ↓, Space, Enter, PageDown. Back: ←, ↑, Backspace, PageUp. Home and End jump to the first and last slide, and Esc (or the × at the top right) ends the show. On a phone or tablet, swipe left or right, or tap the screen (the left third goes back). A slide that is too full is shrunk to fit.

The Slides section of the setup dialog sets the background (plain, dark, navy, sepia, any color such as #102a43, or a picture chosen with Choose picture…; the picture is saved with the document, in its images folder or in the .zip), the transition between slides (fade, slide or none) and whether list items appear one at a time on each key press. The picture can fill the page (cropping the edges), fit whole inside it, or be stretched to it (Picture fits the page), and it can be faded toward dark or light so it does not overwhelm the text; the text color follows. A small sample below the settings shows the result with some text on it. Reduce the picture's size shrinks the picture to at most 1920 pixels on a side as a JPEG, for a smaller file; leave it off for logos and frames, which would lose sharpness. The settings are stored as backgroundfit (fill, fit, stretch) with the others below. They are stored in the front matter as background, backgroundfade, transition and reveal: bullets. The background is used in the show, not in print or Word files.

View ▸ Slide sorter shows every page (the text between two page breaks) as a thumbnail in the deck's look. Drag a thumbnail to move it (on a touch screen, drag the ⠿ grip beside its number). The buttons under each thumbnail add a blank page after it (+), duplicate it, or delete it. Double-click a page to close the sorter and go to it. Done or Esc applies the changes as a single step that Ctrl+Z undoes; Cancel discards them; Ctrl+Z inside the sorter undoes its last change. Videos and audio appear as labeled placeholders. Footnotes and numbered items renumber by their new position.

Dictation

Press the microphone button (or Ctrl+Shift+Space) and speak; press it again to stop. The words go where the cursor is: the document, the Markdown, or the AI prompt line. The first time, the browser asks to use the microphone.

  • The browser (the usual choice): the words appear as you speak. It works in Chrome, Edge and Safari, not in Firefox, and needs an internet connection (the browser sends your voice to Google or Apple to recognize it). It uses your browser’s language. In English you can say period, comma, question mark, colon, new line and new paragraph.
  • This AI provider (choose it in Set up AI): Simple Write records while you speak and, when you stop, sends the recording to OpenAI, Gemini or your own Whisper server, which writes it out with punctuation, and with math as equations when you say formulas (“q equals h A delta T”). It costs a little per minute on your key.

Speech from a recording: Insert ▸ Speech from an audio file writes out the speech in an .mp3, .m4a, .wav, .ogg or video file as normal text at the cursor (the audio itself is not inserted). It uses the AI provider from Set up AI (OpenAI, Gemini or a Whisper server), whatever the dictation setting. Long recordings are cut into pieces at quiet moments and the text arrives piece by piece; Esc stops. Your recording is sent to the provider, so use it only for audio you are allowed to share with them.

Your computer may also have dictation of its own (on a Mac: press Fn twice, or 🌐), which works in Simple Write too, and on newer Macs without the internet.

The AI prompt line

The line at the bottom sends the document, or only the selected text, to an AI model together with what you type, for example “Fix the grammar”, “Summarize in five bullet points”, “Turn this into a table” or “Check the units in these equations”. The small label shows what will be sent: Selection or Document. If the document is empty, the AI writes from scratch. The menu next to Send says where the answer goes:

  • New tab: a new Simple Write tab with the answer, leaving your document as it was (allow pop-ups for this page if the browser blocks it).
  • Replace: the answer replaces the selection or the whole document. Ctrl+Z undoes it.
  • Insert below / Add at the end: the answer goes after the selection, or at the end of the document.

The text is sent as Markdown, so equations go as LaTeX and come back as equations. Esc or Stop stops a long answer; ↑ brings back earlier instructions. View ▸ AI prompt line hides the line.

Choosing the AI: click the button at the left of the line (or View ▸ AI provider and model). Pick a provider, paste its API key, and type or pick a model from the list the provider sends. OpenAI, Anthropic (Claude), Google Gemini and OpenRouter need a key from their websites, and using them may cost money. Ollama runs free models on your own computer: install it from ollama.com, get a model (ollama pull llama3.2), and keep it running; if Simple Write cannot reach it, start Ollama with the environment variable OLLAMA_ORIGINS=*. Other works with any OpenAI-compatible server, such as LM Studio. Keys are kept only in this browser and sent only to their provider; don't save a key on a shared computer (Forget removes it).

AI answers can be wrong, even when they look right. Check them, especially math and numbers.

Notes to the AI inside the text

You can write a request exactly where it applies, in the form [ai: your request]. The notes show in purple. Insert ▸ Note to the AI (Ctrl+Alt+I) types one for you; with text selected, the selection becomes the request.

  • Carry them out: leave the prompt line empty and press Send (the small label then says how many notes there are). The AI sees the whole document, so each note has its context, and returns text for each note. That text takes the place of the note, and nothing else in the document changes. The answer can go to a new tab or into this document (Ctrl+Z undoes it).
  • Use them as context: if you do type an instruction in the prompt line, the notes in the text it sends are explained to the AI as your remarks about the nearby text, and it leaves them out of its answer.

Examples: [ai: explain this in two sentences] on a line of its own, or inside a sentence, Heat is [ai: the standard definition] and flows from hot to cold. A note on its own line may be replaced by several paragraphs, a list, a table or an equation; one inside a sentence is replaced by inline text. Notes inside code and equations are ignored. A note is plain text in the Markdown file, so remove any that are left before you share the document.

Copying and pasting

  • Copy from Simple Write puts two things on the clipboard: formatted text with Word-ready equations (MathML) for Word, email and other tabs, and Markdown for AI chats and plain-text editors.
  • File ▸ Copy all as Markdown copies the whole document for an AI chat; Copy all as formatted text copies it for Word or an email.
  • Paste converts formatted text from web pages, Word, Google Docs, AI chats and Simple Solver, equations included. Plain text is read as Markdown. Ctrl+Shift+V pastes plain text as it is.

What the Markdown looks like

Simple Write uses GitHub-flavored Markdown plus the conventions of Pandoc and pandoc-crossref for what plain Markdown lacks, so the files can also be turned into Word, PDF or LaTeX with Pandoc.

---
numbersections: true            <- page and document setup, at the top
bibliography: references.bib
---

# Introduction {#sec:intro}

Inline math $\dot{m} c_p \Delta T$ and a footnote[^1].

$$
q'' = -k \frac{dT}{dx}
$$ {#eq:fourier}

![Temperature profile](images/plot.png){#fig:profile width=50%}

: Properties of air {#tbl:air}

| Property | Value |
|:--|--:|
| $\rho$ | 1.2 |

See @eq:fourier, @fig:profile and @tbl:air, as shown in [@incropera2007; @cengel2015].
A {==sentence==}{>>Francisco: check this<<} with a comment.

<div align="center">

A centered paragraph.

</div>

<!-- toc -->
<!-- tocstop -->

[^1]: The footnote text.

What is left out, and why

Simple Write leaves out what Markdown cannot hold or what few people use: merged table cells, text boxes and shapes, mixing one and two columns on a page (columns are one setting for the whole document), per-paragraph tab stops (tab stops are for the whole document), sections with different page layouts, track changes, mail merge, macros, styles of your own, and per-paragraph line spacing (it is set for the whole document). Empty paragraphs are not kept in Markdown, so use spacing rather than blank lines.

Drafts are kept in this browser only. Save your documents to files, especially on shared or school computers.
